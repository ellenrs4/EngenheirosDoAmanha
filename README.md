# 🌐 Engenheiros do Amanhã

🚀 **Engenheiros do Amanhã** é um site responsivo criado para apresentar seções com conteúdo educacional sobre robótica.  
Este projeto tem foco em layout visual limpo e usabilidade, utilizando HTML, CSS e um pouco de JavaScript para navegação/interatividade.

👉 Visite o site ao vivo: https://ellenrs4.github.io/engversao2/

---

## 📌 Sobre o projeto

O objetivo do **Engenheiros do Amanhã** é construir um site simples e funcional que:
- Apresente conteúdo organizado em seções
- Mostre habilidades de layout em HTML/CSS
- Demonstre responsividade em diferentes telas
- Utilize boas práticas de estrutura e organização de código

Seções típicas do site:
- Cabeçalho com menu de navegação
- Seções de conteúdo educativo
- Rodapé com informações de contato

Este projeto é ideal para demonstrar **aptidão em Front-End e design de interfaces**.

---

## 🚀 Tecnologias utilizadas

Este projeto foi desenvolvido com:

- 🟦 **HTML5** ― estrutura de conteúdo
- 🎨 **CSS3** ― estilos e layout responsivo
- ⚡ **JavaScript** ― scripts para pequenas interações (se aplicável)
